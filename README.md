# foobar2000 二维随机偏好

用一个二维小球调整本地歌单的播放顺序。

**← 极少听　最常听 →　　↑ 风格跳跃　↓ 风格相似**

两个方向可以组合，中心为均衡随机。偏好只改变先后顺序，每轮仍会覆盖歌单中的全部歌曲，不自动重复已经尝试过的曲目。

[下载 v1.0.9](https://github.com/CuteHeibai/foobar-smartshuffle/releases/tag/v1.0.9) · [反馈问题](https://github.com/CuteHeibai/foobar-smartshuffle/issues) · [开发说明](docs/development.md)

## 选哪个版本

| 功能 | 完整版 `full` | 独立插件版 `core` |
| --- | --- | --- |
| 二维偏好小球、8 首预览、应用与取消 | 中文主题内面板 | 独立原生窗口 |
| 每轮全覆盖、按歌单保存进度、手动插队 | ✓ | ✓ |
| 收听频率统计、本地音频风格分析 | ✓ | ✓ |
| 启动检查 GitHub 更新 | ✓ | ✓ |
| 中文黑灰绿主题、分栏、歌词／队列 | ✓ | 保留已有界面 |
| 拼音／罗马音／歌词搜索、歌手资料、补封面 | ✓ | 不安装主题相关功能 |
| 主题字体、菜单汉化和列表交互调整 | ✓ | 保留已有设置 |
| Columns UI、JSplitter 依赖 | 需要 | 不需要 |

- `foobar-smartshuffle-full-1.0.9.zip`：完整功能包，包含主题、原生插件、音频分析运行时和安装／恢复脚本。
- `foobar-smartshuffle-core-1.0.9.zip`：独立插件包，包含原生偏好窗口、调度核心、音频分析运行时和安装／恢复脚本。不会切换界面或改动字体、歌词插件。
- `foo_smartshuffle.fb2k-component`：单独的原生组件，带偏好窗口与更新检查；不包含分析运行时。需要声学风格分析时，请下载上述 ZIP 包。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

两个 ZIP 包均适用于 **Windows、foobar2000 2.25.8 x64 便携版**，安装脚本需要 **Python 3.10+**。分析运行时已经打包，不需要自行配置 Python 音频依赖。

## 安装

解压所选 ZIP 包，在包内运行：

```powershell
.\scripts\install-public.ps1 -FoobarRoot 'D:\Apps\foobar2000'
```

安装器会识别包的版本类型，正常退出播放器、备份配置和歌单，安装后重新打开。已有输出设备和音量设置保留。

完整版需要先安装 [Columns UI](https://www.foobar2000.org/components/view/foo_ui_columns) 与兼容的 JSplitter；组件获取方式可参考 [Verdant](https://github.com/superziper/verdant-foobar2000-theme)。歌词栏需要另外安装 ESLyric。包内含 MIT 许可的 UI Wizard，不附带 foobar 主程序、Columns UI、JSplitter 或 ESLyric DLL。

独立插件版不需要这些界面组件。完整版用户若要恢复之前的界面，请先运行原完整版备份的恢复脚本，再安装独立版；独立版安装器不会删除已有主题。

备份位于 `smartshuffle-backups/<时间>/`。运行其中的 `restore.ps1` 可恢复安装前的配置、歌单和受影响组件。

完整版首次打开时，窗口约占当前显示器可用面积的 **40%**，纵横比按屏幕形状适配三栏布局。手动调整后的尺寸会保留；插件设置里的“一键恢复默认布局”会重新按当前显示器计算大小。从 v1.0.5 及更早版本升级时会应用一次比例默认尺寸。

在 **视图 → 外观 → 浅色／深色** 切换主题，选择会自动保存。浅色版使用浅灰背景、白色面板、深灰文字和深绿色控件，菜单、搜索、歌词面板与二维偏好坐标系同步适配。两套配色共用布局和播放功能，切换时保留窗口大小与播放进度。

## 使用

完整版从底部播放模式菜单选择“调整随机偏好…”。独立插件版从 foobar 菜单选择 **播放 → 随机偏好 → 调整随机偏好**。

拖动小球或使用方向键调整，两轴可同时生效。上方预览接下来 8 首歌曲，点“应用”后才改变剩余顺序；取消或关闭窗口会保留原顺序。调整期间使用固定随机种子；播放状态或歌单变动后，预览会重新生成。

- 每个歌单保存自己的偏好、轮次和剩余歌曲，重启续接。
- 歌曲开始播放即计入本轮，跳过也算已尝试。手动重播、上一首和单曲循环允许重复。
- 新增歌曲加入剩余集合，删除歌曲从集合移除；重命名和排序不清空轮次。同一路径及子曲目每轮只自动出现一次。
- 手动播放队列优先，之后接回本轮。内部托管列表负责调度，保留来源歌单的顺序。
- 频率采用已有累计次数和安装后的近 30 天有效收听次数；不会补造历史记录。
- 风格以本地声学特征为主、流派标签为辅。尚未分析的歌曲先使用标签，缺少两者时保持中性。后台分析可在“播放 → 随机偏好”中暂停／继续。

完整版可在 **文件 → 首选项 → 工具 → 智能随机** 一键切换原版／新版界面，也可从 **播放 → 随机偏好** 操作。切换会正常退出并重启播放器；两套界面分别保存，当前歌单、收听记录和音频输出共用保留。原版模式停用智能调度与后台任务。需要首次安装前的完整备份才能启用此功能。

## 更新

每次启动在后台向本仓库的 GitHub Releases 检查一次。找到新版本时显示下载窗口，并按当前安装类型提供完整版或独立版安装包。无更新或连接失败时保持安静，不影响播放。

“播放 → 随机偏好 → 检查更新…”可以手动检查，也可关闭启动检查。发现新版本后点击 **更新并重启**，播放器会在后台下载对应类型的安装包，核对文件大小和 SHA-256，再正常退出、备份、安装并重新打开。检查更新本身不会中断播放；安装失败会恢复并重新打开原版本，原因保留在更新窗口。

旧版若尚无“更新并重启”按钮，需要先手动安装一次新版组件。软件内更新同样需要 Python 3.10+，不会自动安装系统 Python。当前发行通道包含 GitHub 上的测试版，草稿和未完成上传的安装包不会参与更新。

更新检查只请求公开版本信息，不上传音乐路径、音频、歌词或收听记录。[更新机制说明](docs/updates.md)

## 完整版界面

黑灰背景、绿色强调、中文侧栏与底部播放器；上方音乐库和歌词栏宽度可拖动调整，分隔细线始终可见。底栏自动布局，不提供内部组件宽度拖动；播放按钮尽量保持在整个窗口中央，空间不足时缩短进度条并避让两侧内容。右侧默认显示 ESLyric，也可切换待播队列；队列保留剩余歌曲数，隐藏轮次数字。播放顺序菜单保留顺序、列表循环、单曲循环和智能随机。

歌单封面和歌单页均有绿色播放按钮，点击即可播放整张歌单；智能随机继续该歌单保存的轮次。顶栏菜单点击展开和切换，点击外部或按 Esc 关闭。

歌曲、歌单与队列支持拖动排序，歌曲支持 Ctrl＋左键逐首多选、批量复制／移动及原生格式转换。左键长按后拖动整行排序，多个已选曲目可一起移动；原地放置不显示插入线。双击歌曲会插到队首并立即播放。右键菜单保留原生插件命令；移到回收站前会显示文件确认。

搜索支持中文拼音、日语罗马音和本地歌词，带时间轴的歌词结果可跳转至对应句。歌手资料与头像单独联网核验；缺失专辑封面在启动后后台查找，图片和来源保存在个人缓存中。

[列表与封面](docs/editing-and-covers.md) · [搜索与歌手资料](docs/search-artists.md)

音频输出菜单读取系统已有的 WASAPI／ASIO 设备，是否支持 ASIO 取决于声卡驱动。英文采用 Inter，中文明确使用微软雅黑 UI，日文假名使用 Yu Gothic UI。Inter 随包提供并保留开放字体许可，仅在播放器进程内加载；微软字体只调用系统已有文件，不放入发布包，也不修改系统默认字体。[ESLyric 软件渲染工具](docs/eslyric-investigation.md)是另行选用的源码工具，公开安装器不替换歌词 DLL。

## 开发

源码使用 C++20、foobar SDK、JSplitter JavaScript 和隔离的 Python 分析运行时。

```powershell
.\scripts\fetch-deps.ps1
.\scripts\build.ps1 -TestsOnly
.\scripts\build.ps1
.\scripts\build-analyzer.ps1
.\scripts\package-public.ps1
```
