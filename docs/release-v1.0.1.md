# v1.0.1 测试版

修复主题的窗口控制、歌曲右键菜单和歌词默认显示，并把原生播放模式与智能随机合并到一个入口。

- 补齐 MIT 许可的 UI Wizard 组件，恢复窗口移动、调整大小、最小化和最大化。默认 1180×780，后续启动保留手动大小。
- 歌词放在右栏第一项并默认显示，原生 ESLyric 使用已保存的面板设置。
- 原生歌曲右键和插件子菜单由 SDK 读取，用深色菜单呈现；音频输出菜单也使用统一样式。
- 一个播放模式菜单选择智能随机、原生顺序/循环/随机，并打开二维偏好。从智能随机切回顺序播放能接回来源位置，保持当前歌曲及播放进度。
- 小球逐帧合并刷新，复用背景缓存，加入半透明层、短拖尾与渐变坐标系；页面切换加入短动画。
- 音乐库、主内容、歌词／队列，以及底部歌曲信息、播放、输出区域可拖动分隔线调宽窄，自动保存。插件设置页提供“一键恢复默认布局”，保留歌单、历史、偏好和输出。
- 顶栏菜单开关复用已绘制画面，原生菜单请求直接隐藏歌词，减少额外等待。二级菜单悬停立即重绘，顶栏菜单之间支持悬停切换，移开后自动关闭。
- 窗口放大缩小时，字体、行高、封面及主要间距一起调整；忽略最小化时的临时小画布，保留可用布局。
- 最大化歌曲列表悬停合并到一帧，仅复制旧行和新行；其他局部刷新也只复制对应区域。
- 缓存画面改用 GDI+ 灰度文字抗锯齿，新建歌单按实测文字高度分行。
- 拼音、首字母、日语罗马音、近似拼写和本地歌词搜索，后台缓存索引并显示命中片段。
- 每次打开歌手页静默核验姓名、标识与发行署名并下载独立头像，缓存资料与图片来源。离线保留缓存，同名不确定时不自动替换。
- 歌曲及智能队列右键提供“移到回收站”，确认后由系统回收；外部 CUE 不支持该操作。
- 主题、Columns UI 公共及已有插件字体角色、已识别的 ESLyric 配置统一为 Segoe UI，中文使用系统字体回退。硬编码字体或自定义 XML 需插件自身支持；不分发 Spotify 专有字体。
- 临时播放来源及托管列表在停止或不再使用后清理；测试歌单完成后删除，保留原歌单。

桌面 ZIP 包含组件、主题、独立分析运行时、UI Wizard 及备份安装/恢复脚本。请先安装 Columns UI 和兼容的 JSplitter；歌词需要 ESLyric。公开安装不替换 ESLyric DLL。

真实 foobar2000 2.25.8 x64 副本已验证窗口接口、模式交接、实际菜单命令、整轮播放、自然续轮、CUE、插队、失败停止、临时歌单清理和重启。鼠标手感、可见边缘和高 DPI 仍需人工观察；没有使用 Computer Use。
