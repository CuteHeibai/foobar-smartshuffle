# 界面设计规范

完整版主题的唯一视觉方向：**Apple Music（macOS 桌面版）式的简约、清爽**。旧的“黑灰绿”“桌面唱片室（暖白／酒红）”方向已废弃，不再作为参考。本文件与 `theme/verdant/core/tokens.js` 冲突时，以本文件为准，再同步修改令牌。

## 感受与原则

- 内容优先：封面和歌名是主角，界面本身安静、留白充足。
- 少即是多：能用间距和字重区分的，不加分隔线、底框或灰色色块。
- 一致：同类元素使用同一行高、同一缩进、同一圆角档位。
- 克制的颜色：中性灰阶加一个强调色；大面积颜色只来自封面。

## 布局

- 三段结构：左侧栏、主内容区、底部播放栏；歌词／队列为可收起的右栏。
- 侧栏：默认约 220–260px，不随大屏无限放宽。条目带线性图标，按“音乐库／个人／歌单”分组，组标题为小号灰字。同组条目行高、图标列和文字起点完全对齐。
- 主内容区：左右边距统一；页面以粗体大标题开头。专辑、歌单页头采用“封面 + 标题 + 元信息 + 操作按钮”一行组织，操作按钮与元信息共用基线。
- 底栏：传输控件居中；歌曲信息、进度在同一视觉组内；右侧音量与工具图标对齐在一条中线上。
- 全屏：左封面、右歌名与歌词；背景使用封面取色或模糊的氛围底色。控件与进度条成组对齐，不在不同高度各自漂浮。

## 字体

- 可以选用系统已有或随包分发的字体，按字重建立层级：大标题 Bold／Semibold，分区标题 Semibold，正文 Regular，辅助信息 Regular 小一号、次级灰。
- 中文使用微软雅黑 UI，日文假名使用 Yu Gothic UI；字体经 `ssFitFont` 适配布局盒，所有尺寸随 `ssDensity` 缩放。
- 不注册系统全局字体；独立插件版不改用户原有界面字体。

## 颜色

- 颜色只通过 `ssPalette` 的语义色使用，深浅两套同步维护。不要重映射 `RGB`／`RGBA` 字面值（封面遮罩依赖黑白原值）。
- 中性色：浅色以白色和极浅灰为底，深色以近黑和深灰为底；文字分三级（主文字、次级、辅助）且彼此可区分。
- 强调色只用于当前项、播放状态和主要按钮。

## 形状与层次

- 圆角三档：`ssRad('sm')`＝4、`md`＝8、`lg`＝12（随密度缩放）。行悬停与小按钮用 sm，封面、卡片、按钮用 md，弹窗与大面板用 lg。胶囊控件用高度一半；圆形保持圆形；视口四角遮罩保持 `M.radius`。
- 浮层（菜单、弹窗、拖动浮层）用柔和投影和 1px 低对比描边，不使用粗边框。
- 封面使用 md 圆角和轻微投影。

## 动效

- 按经过时间计算，单次不超过 200ms，结束后回到静态缓存；支持减少动态效果。
- 滚动、拖动、失焦、最小化、弹窗期间暂停装饰动画。

## 避免

- 绿色强调、Spotify 式布局与配色。
- 同一组内混用行高或缩进；按钮外再套灰色大块。
- 全部文字同一字重；用分隔线代替留白。
- 为装饰新增整窗重绘或无上限位图缓存。
