# 桌面唱片室主题

## 已确认的设计约束

浅色优先，暖白背景、深灰文字、酒红强调色，适中密度，保留深色模式。手机播放器参考仅限图标风格；不能借用其排版、导航、封面比例或页面布局。沿用现有 Inter／微软雅黑 UI 与原生 GDI 绘制。

左导航和底部播放栏常驻；歌手及统计作为一级入口。主区按桌面宽度组织多列封面、横向资料和紧凑歌曲列表。歌词／队列由底栏打开，保存选择；窗口过窄时自动收起，恢复宽度后恢复。自动收起后仍可点击入口临时展开。

全部页面继承统一语义配色。歌手页保留专辑与曲目行为；首页使用真实音乐库，不伪造听歌记录或为展示而启用个人记录。全屏默认采用封面与曲目信息左右分栏。

## 验证入口

`tests/record_room_layout_tests.js` 检查抽屉默认、持久化、自动收起、首次点击恢复、零宽绘制与原生歌词隐藏。主题、几何、选择、播放、滚动和个人页沿用现有回归检查。

`tests/host_record_room.py` 通过独立 JSplitter 实际绘制位图，覆盖深浅色和三种窗口尺寸；结果位于本地 build/record-room。截图证明绘制状态，不替代实际播放与设备听感检查。

交付独立体验版和验证记录，不将测试组件、个人缓存或第三方素材打包发布。
