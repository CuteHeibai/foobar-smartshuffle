# 列表操作、补封面与汉化

适用 v1.0.3，已在 foobar2000 2.25.8 x64 + 本机组件组合验证。

## 歌单和歌曲

- 左侧歌单按住左键上下拖动，保存真实歌单顺序。内部调度歌单与临时播放来源不显示。
- 歌曲单击选择；Ctrl 点选切换选中状态，Shift 点选选择连续范围。从未选中的行或列表空白处按住左键拖动，可框选多首。
- 先选中歌曲，再按住选中行拖动，可以移动整组选区。拖动后显示排序切到“手动顺序”，源歌单真实顺序同步改变；文件不会移动。
- 拖到列表视口边缘会自动滚动。右侧队列也可用滚轮浏览，按住行拖动改变先后顺序。
- 右侧“优先播放”与本轮剩余歌曲分别排序，优先队列始终先播放。原生顺序模式下，队列拖动调整来源歌单顺序。智能或锁定歌单禁止手工排序／移除，可复制歌曲到普通歌单。
- 右键选区可添加／移动到已有歌单或新歌单、加入待播队列、从普通歌单批量移除；原生“转换”菜单会收到整个选区。转换格式、编码器和目标文件由原生转换器对话框选择。
- 歌单标题右上角“添加文件夹”使用 foobar 原生目录选择器批量导入。它支持已有内容的普通歌单。

双击歌曲会先把它加入优先队列，然后立即播放；原有队列按原先顺序接续。行首播放图标仍可直接播放。歌词匹配结果单击会播放该曲并定位到匹配行，只有带时间轴的歌词可以精确跳转；无时间轴的文本只播放歌曲。

歌曲或队列在拖动期间被更改时，旧排列请求会被拒绝，请重新拖动。重复文件按行位置区分；智能随机仍按路径及子曲目去重，且每轮不放回。

## 启动补封面

启动主题后约 4 秒开始，后台逐首检查音乐库及可见歌单的实际封面；每次仅检查一个文件。嵌入封面、已有外部封面始终优先。

没有封面的曲目按专辑合并：有 MusicBrainz 专辑 ID 时直接使用，否则要求专辑名、歌手名准确匹配且身份唯一，再下载封面。查不到、同名冲突或网络失败的记录保持占位，下次启动可再次联网尝试。成功图片复用，不会每次重下。

缓存为 `profile/smartshuffle/covers.json` 和 `profile/smartshuffle/album-covers/`，记录来源及曲目映射；不在音乐目录新建图片，也不写歌曲标签。联网请求只发送查找所需的歌手、专辑或 MusicBrainz ID。网络工作在独立低优先级进程完成；搜索／歌手核验可让封面任务让出后台工具。

采用 [MusicBrainz / Cover Art Archive API](https://musicbrainz.org/doc/Cover_Art_Archive/API) 的 500 像素正面图；图片权利归原权利人。公开发行包不包含用户封面或歌手缓存。

## 已安装插件的汉化

主题原生菜单和标准 Windows 设置控件共用 `profile/verdant/locale/zh-CN.json`。本版包含 355 条翻译，重点覆盖 Columns UI、JSplitter、SACD 的常用英文控件，以及转换、输出、歌词等菜单。

原生层只替换匹配的对话框标题、静态标签、按钮和标签页文字，保留控件 ID、命令编号和编辑框内容，不修改第三方 DLL。已经汉化的组件继续使用原有中文。

第三方自绘面板、部分下拉选项、提示和运行时生成的文字不属于完整覆盖范围，不能称为所有插件完全汉化。字体名称和技术格式保留原名，未收录的文字沿用原文。删掉词典中的对应条目并重启，可以停用某条翻译。
