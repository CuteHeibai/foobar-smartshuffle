## 新增

- 歌单封面与歌单页增加播放按钮，一键播放整张歌单。智能随机接着已保存的轮次播放，保留手动插队。
- 完整版支持一键切换原版／新版界面，入口位于“首选项 → 工具 → 智能随机”和“播放 → 随机偏好”。切换需要重启，两套界面分别保存；歌单、收听记录与音频输出共用保留。

## 界面与交互

- 多选改为 Ctrl＋左键；左键长按后拖动整首歌曲行调整顺序，原地放置不显示插入线。
- 顶栏菜单改为点击展开、切换与关闭，移开鼠标保持打开；列表右键菜单保留原来的操作方式。
- 底部播放按钮尽量保持在整个窗口中央，调整栏宽时按内容避让。
- 分栏边界始终显示细线，增强浅色模式下分隔线、菜单边框和坐标网格的对比度。
- 小球绘制合并到帧，复用静态面板；半透明短拖尾按时间采样，统一偏好面板按钮样式。
- 修复拖动歌曲或进度条经过歌单播放按钮时的误触发。

## 下载与升级

- `full`：主题及全部功能；升级保留布局与配色。
- `core`：二维偏好、调度、分析与更新检查，保留现有界面。

下载对应 ZIP，解压后运行 `scripts/install-public.ps1 -FoobarRoot '你的便携版播放器目录'`。安装器会正常退出播放器并先做备份。完整版一键界面切换需要有效的安装前备份，公共包不附带第三方界面组件 DLL。
