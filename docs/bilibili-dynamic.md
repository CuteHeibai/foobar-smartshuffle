最近给 foobar2000 折腾了个随机播放插件，放 GitHub 了。

主要想解决两件事：随机时能把歌单完整播一轮；想偏向常听、少听，或者风格相似、风格跳跃时，可以自己调。

做成了一个二维小球：
← 极少听　最常听 →
↑ 风格跳跃　↓ 风格相似

拖动后会预览接下来 8 首真实待播歌曲，点应用才生效。两个方向可以组合，中心就是均衡随机；偏好只影响先后顺序，每轮仍然覆盖整个歌单。

听歌记录会逐渐积累，风格分析在本地完成。另外改了一套中文黑灰绿界面，能看待播队列、歌词和分析进度。

最近也补了拼音、日语罗马音和本地歌词搜索。歌手页会单独联网核验资料、缓存独立头像，窗口和分栏宽度也能自己调整。

源码和测试版：
https://github.com/CuteHeibai/foobar-smartshuffle

目前主要按 Windows + foobar2000 2.25.8 x64 便携版测试，安装前看一下 README，建议先拿副本试。欢迎提 bug 和使用反馈。
