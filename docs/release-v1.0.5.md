# v1.0.5

新增启动检查更新，并提供两种安装包。

- **完整版 `full`**：二维随机偏好、本地分析、中文主题及全部界面功能。
- **独立插件版 `core`**：二维随机偏好、本地分析和播放调度，保留现有主题、字体和歌词设置。无需 Columns UI 或 JSplitter。
- 独立版新增原生偏好窗口，支持渐变坐标系、拖动小球、8 首预览、方向键及应用／取消。
- 每次启动后台检查本仓库的 GitHub Releases；有新版本时提供当前版本类型的下载入口，可关闭启动检查，也可手动检查。
- 多选改为 Ctrl＋右键逐首切换，左键拖动直接调整顺序，支持成组移动。
- 修复快速跨行悬停和拖动刷新时歌曲内容漏画，以及歌单右键误报“所选歌曲已变化”。
- 字体改为 Inter 与微软雅黑 UI，标题采用较轻的字重，文字使用抗锯齿并按整像素恢复缓存；字体仅在播放器进程中加载，独立版不改现有界面字体。
- 更新 README，补充开发约束、构建和接口说明。

下载 `full` 或 `core` ZIP 后解压，运行 `scripts/install-public.ps1 -FoobarRoot <便携版目录>`。升级会自动创建备份。单独的 `.fb2k-component` 不含音频分析运行时。
